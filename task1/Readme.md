## Что делает

Два приложения обмениваются данными через bind-mount'ы хост-каталогов:

1. **worker1** — читает все файлы из `/var/data` (хост `./data`),
   берёт из каждого файла первую строку и пишет их в
   `/var/result/data.txt` (хост `./result-1/data.txt`).

2. **worker2** — читает `/var/data/data.txt` (тот же хост-каталог
   `./result-1`), находит минимальное число, возводит его в третью
   степень, пишет результат в `/var/result/result.txt`
   (хост `./result/result.txt`) и дублирует его на экран.

## Схема монтирования

| Хост-каталог | Контейнер | worker | Назначение |
|---|---|---|---|
| `./data`     | `/var/data`   | worker1 | исходные файлы |
| `./result-1` | `/var/result` | worker1 | промежуточный `data.txt` |
| `./result-1` | `/var/data`   | worker2 | вход — тот же `data.txt` |
| `./result`   | `/var/result` | worker2 | финальный `result.txt` |
